THE IDEA BEHIND THE HUB

Campus life, closer.

StudentHub is a student portal concept designed to make university information, events and community easier to discover and participate in.

✦

Our vision

A connected campus where every student can discover opportunities, find useful information and take part in the experiences that shape university life.

◎

Our mission

Bring campus activities and student resources into one clear, accessible and responsive digital space, while demonstrating core Web Technology concepts.

WHAT WE WANT TO ENABLE

Small actions.
Better campus life.

03

04

Access campus news, FAQs and useful student information.

Project context

StudentHub is an academic demonstration for the AIUE203 Web Technology practical series. It brings HTML5, CSS3, JavaScript, JSON, Fetch API concepts, form handling, authentication workflows, database design and administration into one integrated project. The GitHub Pages deployment is the static demonstration edition; the PHP/MySQL implementation is intended to run locally through XAMPP or on a PHP-capable server.
